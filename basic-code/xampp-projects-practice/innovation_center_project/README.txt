Innovation Center Project Submission Portal
=============================================
1. Create a MySQL database by importing db.sql in phpMyAdmin.
2. Update database credentials in config.php if needed.
3. Put this folder inside XAMPP htdocs (or your PHP server root).
4. Make sure the uploads folder is writable.
5. Open http://localhost/innovation_center_portal/index.php
6. Optional: replace uploads/default.png with a real default poster image.

Required stack: PHP + MySQL + HTML + CSS.
